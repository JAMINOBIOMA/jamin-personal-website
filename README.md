# Jakiel Jamin Obioma — Personal Website

A responsive, custom-coded personal portfolio for Data Science, SQL analytics, AI/LLM evaluation, IT support, project coordination, and J Quantum Tech Solutions.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive dark technology theme
- `script.js` — mobile navigation and current year
- `assets/` — place optional images, résumé PDF, and project screenshots here

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `jamin-personal-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will usually be `https://YOUR-USERNAME.github.io/jamin-personal-website/`.
6. You can later add a custom domain through **Settings → Pages → Custom domain** if you own one.

## Alternative: Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually** (the wording may vary).
3. Drag the extracted website folder into the deployment area.
4. Netlify will provide a public URL; you can customize the site name in site settings.

## Before publishing — important content checks
- Confirm the name spelling and professional headline.
- Confirm `obiomajamin@gmail.com` is the email you want public.
- Confirm LinkedIn and GitHub links are correct.
- Project cards currently describe portfolio directions, not verified completed deliverables. Update each card to link directly to a real repository and add truthful screenshots/results as each project is completed.
- Add a résumé PDF only if you want it publicly accessible. If adding one, use a safe filename such as `assets/Jakiel-Jamin-Obioma-CV.pdf` and link it from the page.
- Replace or add a professional headshot if desired. The current hero artwork is CSS-generated, so no image assets are required.
- No contact form backend is configured. The contact links open the visitor's email application.

## Editing basics
- Update wording and links in `index.html`.
- Change colors near the top of `styles.css` under `:root`.
- Keep the three main files together in the same folder.
